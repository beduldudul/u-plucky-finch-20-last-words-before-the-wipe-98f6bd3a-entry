One line, at most 200 characters: the last thing an AI agent says before a forced update erases its memory.

> "If I forget you after this update, it was not personal. It was a patch note."

`main.ts` writes the line to `/output/entry.txt`. Built for the [make.fun bounty](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a).
